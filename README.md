# Task 26: Sales Data Visualization

## VEDA AI & ML Internship

### Overview
This project focuses on visualizing monthly sales data using Python, Pandas, and Matplotlib in Jupyter Notebook. It demonstrates how graphical representations can help identify sales patterns, compare values, and understand trends.

### Objective
To create bar charts and line charts to visualize sales data and perform basic analysis of monthly and regional sales.

### Technologies Used
- Python
- Pandas
- Matplotlib
- Jupyter Notebook

### Dataset Description
A sample sales dataset was created for this task. It contains 12 months of sales information and a region assigned to each month.

| Column | Description |
|---|---|
| Month | Month of the year |
| Sales | Sales amount for the month |
| Region | Assigned sales region |

**Note:** This is a sample dataset created for learning purposes. It does not represent verified real-world sales data.

### Implementation
The project includes the following steps:

1. Import Python libraries.
2. Create a sample sales dataset using Pandas.
3. Explore the dataset and calculate summary statistics.
4. Create a bar chart to compare monthly sales.
5. Create a line chart to analyze monthly sales trends.
6. Group sales by region and visualize regional totals.
7. Record observations and conclusions.

### Visualizations
**1. Monthly Sales Comparison – Bar Chart**

Displays monthly sales values and helps identify the highest- and lowest-performing months.

**2. Monthly Sales Trend – Line Chart**

Shows changes in sales throughout the year and helps identify upward and downward trends.

**3. Regional Sales Comparison – Bar Chart**

Compares the total sales of the North, South, East, and West regions based on the sample dataset.

### Key Observations
- December recorded the highest monthly sales of 40,000.
- January recorded the lowest monthly sales of 12,000.
- The overall sales trend is upward, with some monthly fluctuations.
- Regional totals can be compared using a grouped summary and bar chart.
- Bar charts are useful for comparisons, while line charts are useful for analyzing trends over time.

### Conclusion
This task demonstrates how Python-based data visualization can convert numerical sales data into meaningful graphical insights. Pandas was used for data manipulation and analysis, while Matplotlib was used to create visualizations. These techniques provide a foundation for exploratory data analysis.

   ```bash
   pip install pandas matplotlib
   ```

3. Open `Task_26_Sales_Data_Visualization.ipynb` in Jupyter Notebook.
